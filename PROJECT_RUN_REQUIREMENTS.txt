Project Run Requirements
========================

Purpose
-------
This project will read Microsoft Access .mdb files exported from Synergi Electric
and use the exported data to verify parts of a feeder model.


Required System Setup
---------------------
1. Windows
   The current approach uses the Microsoft Access ODBC driver, which is available
   on Windows.

2. 64-bit Python
   Use a 64-bit Python installation because the installed Access ODBC driver is
   64-bit. The project virtual environment currently uses 64-bit Python.

3. Microsoft Access ODBC Driver
   Required driver name:

       Microsoft Access Driver (*.mdb, *.accdb)

   This driver is already installed on the current machine.

4. Python virtual environment
   The project currently has a virtual environment at:

       .venv

   Use this interpreter when running project scripts:

       .venv\Scripts\python.exe


Required Python Packages
------------------------
The current scripts require:

    pandas
    pyodbc

These are already installed in the current virtual environment.

To verify the environment, run:

    .venv\Scripts\python.exe installverification.py


Expected Input Files
--------------------
The project expects Synergi Electric exports in Microsoft Access database format:

    .mdb

Keep raw exported files unchanged. A recommended folder structure is:

    data\raw\        Original Synergi .mdb files
    data\exports\    CSV files exported from .mdb tables
    reports\         Verification summaries and findings


Inspecting an MDB File
----------------------
Use inspect_mdb.py to inspect a Synergi .mdb file before writing verification
logic.

List all user tables:

    .venv\Scripts\python.exe inspect_mdb.py path\to\model.mdb

List tables and columns:

    .venv\Scripts\python.exe inspect_mdb.py path\to\model.mdb --columns

Export all tables to CSV:

    .venv\Scripts\python.exe inspect_mdb.py path\to\model.mdb --export-all --out data\exports

Export selected tables to CSV:

    .venv\Scripts\python.exe inspect_mdb.py path\to\model.mdb --export TableA TableB --out data\exports

Limit preview rows when listing table samples:

    .venv\Scripts\python.exe inspect_mdb.py path\to\model.mdb --preview 5


Recommended Project Workflow
----------------------------
1. Put the original Synergi .mdb file in data\raw.
2. Run inspect_mdb.py with --columns to identify available tables and fields.
3. Export important tables to CSV.
4. Identify tables that represent feeder nodes, lines, switches, transformers,
   loads, sources, capacitors, regulators, and connectivity.
5. Build verification checks one at a time.
6. Save verification output in reports.


Initial Verification Checks to Build Later
------------------------------------------
Useful first checks include:

1. Every line endpoint references a valid node.
2. Every switch or device references valid nodes.
3. Equipment IDs are unique where they should be unique.
4. The expected feeder/source exists.
5. Required ratings and impedance values are populated.
6. Loads are attached to valid buses or nodes.
7. The feeder does not contain unexpected disconnected islands.
8. Counts of major equipment types match expected Synergi/model counts.


Notes
-----
Synergi export schemas may vary between versions and export settings. The first
goal is to inspect the actual tables and columns in the exported .mdb file, then
write verification code around the observed schema.
